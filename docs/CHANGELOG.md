# История версий ПУЛЬСа

## 1.0.0 — 20.11.2026

Первая публичная демонстрационная сборка для потенциальных заказчиков.

**Панель**

- «Пульс»: оценка команды 0–100, динамика, KPI, красная зона, план на сегодня,
  что хорошо и что плохо.
- «Чаты»: список с фильтрами и поиском, вердикт по каждому диалогу, метрики,
  обещания, переписка с пометками и цитатами.
- «Люди»: карточки сотрудников, сильные стороны, зоны роста, сравнение.
- «Обещания»: статусы, просрочки, напоминания.
- «Отчёт»: готовая страница собственнику, печать в PDF, скачивание Markdown.
- «Настройки»: подключение, режим присутствия, правила, уведомления, доступы.
- «Версия»: состав релиза, техническая информация, ссылки.

**Демо-данные**

- 11 чатов открытых линий, 5 сотрудников, 3 линии.
- Реалистичные сценарии бухгалтерии: НДС, УСН, зарплата, кадры, ФНС, сверки,
  блокировка счёта, новый клиент.
- Оценка 0–100 с объяснением и цитатой.
- Утренняя сводка и пятничный отчёт.

**Технически**

- FastAPI + SQLAlchemy + SQLite.
- Панель без сборки: HTML, CSS, JavaScript.
- Демо-контур без подключения к реальному порталу.
- Подготовлена интеграция с Битрикс24: `imbot.v2`, тип `supervisor`,
  `ONIMBOTV2MESSAGEADD`, `imopenlines.session.history.get`.
- Статическая демо-сборка для Netlify.

**Документы**

- `01-КАК-РАБОТАЕТ-БОТ.md` — описание для собственника.
- `02-ТЗ.md` — техническое задание.
- `03-ИНТЕГРАЦИЯ-БИТРИКС24.md` — подключение.
- `04-МЕТОДИКА-ОЦЕНКИ.md` — правила и формула.
- `05-ПИЛОТ.md` — проверка за 14 дней.
- `pulse-owner.pdf` — PDF для собственника.
